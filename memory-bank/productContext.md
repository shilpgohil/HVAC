# Product Context & Domain Standards

## Product Definition
The HVAC Digital Twin is a mission-critical supervisory monitoring and control platform designed for commercial and industrial facilities. It instantiates physical mechanical systems (central chilled water plants, AHU networks, pumps, cooling towers, and terminal VAVs) into software entities.

## Target User Personas
1. **Viewer:** Read-only access to operational overview, schematic, and live telemetry.
2. **Operator:** Can acknowledge alarms, view historical trends, and issue standard two-step setpoint changes.
3. **Engineer:** Full supervisory command authority, manual overrides, tuning PID loops, configuring alarm thresholds.
4. **Administrator:** System configuration, user management, site onboarding, visual layout editor, and full audit logs.
